# Third Person Project

**Third Person Project** is a 501(c)(3) non-profit, community-driven research initiative founded in 2015. This public repository is used to publish the Third Person Project website, found at [thirdpersonproject.org](https://thirdpersonproject.org).

### Website Architecture

The website is primarily a static site built using [Jekyll](https://jekyllrb.com/).

The website also contains an application to add and maintain annotations to the transcripts of archived documents. The annotations application is a work-in-progress. Front-end functionality is built out using [Alpine.js](https://alpinejs.dev/), while the backend uses a NodeJS server with a MongoDB database.
